## About these write-ups

These summaries are based on my workplace support notes. Client names, user identities, domains, mailbox names, internal addresses and original ticket identifiers have been omitted. Internal screenshots and logs are not published here.

“What I did” records the actions in those notes. Follow-up sections identify remaining checks rather than implying they have already been completed. Where a service was restored but its underlying cause was not established, the ticket says so.

The [command reference](docs/command-reference.md) contains optional diagnostic examples for related work; it is separate from the record of actions performed.
